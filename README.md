# EDITORS.ElevationBuilder — Equipment Rack Elevation Builder

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery.

Equipment Rack Elevation Builder: design 19-inch 42U equipment racks, snap equipment modules to rack units (RU), inspect RU clearance, calculate power consumption and thermal BTU heat loads, view front/rear elevations, and export rack schedules.

| | |
|---|---|
| **Opens** | the OS shell (Design → Racks & Infrastructure), or `index.html` standalone |
| **Build** | none — plain web files; `npm test` |
| **Ships** | baked into WEB.Frontend-Assets (`up-stack.sh WEB.Frontend-Assets`), served at `:8080/Softapps/EDITORS/EDITORS.ElevationBuilder/` |
